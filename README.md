# 📊 Customer Shopping Behavior Analysis & Dashboard

## 📌 Project Overview  
This project analyzes **customer shopping behavior** using Python, SQL, and Power BI.  
It transforms raw data into meaningful insights and presents them through an **interactive dashboard**.

---

## 🚀 Project Workflow  

1. **Business Problem Statement**  
   - Define objectives and key business questions  

2. **Data Import & Processing (Python)**  
   - Load dataset into Python  
   - Data cleaning & preprocessing  

3. **Exploratory Data Analysis (EDA)**  
   - Identify patterns and trends  
   - Visualization using Pandas, Matplotlib, Seaborn  

4. **Data Modeling & Storage (SQL)**  
   - Load processed data into SQL database  
   - Perform structured queries  

5. **Data Analysis in SQL**  
   - Customer segmentation  
   - Purchase behavior analysis  

6. **Interactive Dashboard (Power BI)**  
   - Connect SQL to Power BI  
   - Create dashboards for insights  

7. **Project Report & Presentation**  
   - Summarize findings  
   - Create presentation (Gamma AI)  

8. **Version Control (GitHub)**  
   - Upload and manage project files  

---

## 📂 Dataset  

- **File:** `customer_shopping_behavior.csv`  
- **Description:**  
  Contains customer data including:
  - Demographics  
  - Purchase history  
  - Product categories  
  - Spending patterns
