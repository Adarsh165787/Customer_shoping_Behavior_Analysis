📊 Customer Shopping Behavior Analysis & Dashboard
📌 Project Overview

This project focuses on analyzing customer shopping behavior using Python, SQL, and Power BI.
The goal is to extract meaningful insights from raw data and present them through an interactive dashboard for better decision-making.
